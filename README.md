# Volkswagen India Sales Analysis | SQL & Power BI

## 📌 Project Overview

This project focuses on analyzing Volkswagen vehicle sales in India using **SQL Server and Microsoft Power BI**. It demonstrates the process of exploring data quality, validating business rules, analyzing sales performance, and building an interactive dashboard to support data-driven business decisions.

The project combines SQL-based data investigation and analysis with Power BI visualizations to explore sales trends, revenue, customer metrics, and vehicle preferences.

## 🎯 Project Objectives

- Investigate data quality issues, missing values, inconsistent entries, and potential duplicate transactions.
- Validate pricing and discount calculations against business rules.
- Analyze revenue and unit sales across vehicle models and product attributes.
- Track key performance indicators and explore year-wise sales trends.
- Build an interactive Power BI dashboard for exploring sales performance.

## 🛠️ Tools & Technologies

- **SQL Server 2022** — Data exploration, data-quality checks, validation, and business analysis.
- **Microsoft Power BI Desktop** — Interactive dashboard development and data visualization.
- **DAX** — KPI calculations and analytical measures.
- **Power Query** — Data preparation and transformation.
- **GitHub** — Project documentation and version-controlled portfolio files.

## 📊 Key Performance Indicators

The dashboard focuses on the following metrics:

- Total Revenue
- Units Sold
- Average Selling Price
- Discount Metrics
- Customer Metrics

## 🔍 Analysis Performed

### 1. Data Quality Assessment
- Investigated missing values in critical columns.
- Checked inconsistent values in fuel type, gender, city, and state fields.
- Investigated duplicate sales and customer identifiers.
- Examined zero values in important pricing columns.

### 2. Data Validation
- Compared listed prices, selling prices, and discounts.
- Investigated potential inconsistencies in sales records.
- Performed validation queries to support reliable reporting.

### 3. Sales Performance Analysis
- Model-wise revenue and unit sales.
- Sales by vehicle colour.
- Performance by fuel type, transmission, and vehicle variant.
- Year-wise revenue and unit sales.
- Customer metrics across sales dimensions.

### 4. Power BI Dashboard
- Interactive KPI cards and visualizations.
- Slicers for vehicle model, colour, fuel type, transmission, and variant.
- Sales comparisons across multiple business dimensions.
- Vehicle images integrated into the dashboard to improve the user experience.
